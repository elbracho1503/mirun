# MiRun

App para correr: GPS, distancia, ritmo, calorías, metas, splits por km, mapa de la ruta, aviso por voz e historial.

- Funciona sin internet después de abrirla la primera vez.
- No tiene servidor ni cuentas: todos los datos se quedan en el teléfono de cada persona.
- Abrir: https://elbracho1503.github.io/mirun/

Si se cambia `mirun.html`, subir el número de `CACHE_NAME` en `sw.js` para que los teléfonos reciban la versión nueva.
